## 4. 运行备注

上机前建议先做 reference-only 或短时 MuJoCo/Mock 冒烟，确认：

- `q_ref_shaped`、`dq_ref_shaped` 有效且有限；
- 无 fatal safety flag；
- 初始 `startup_blend_duration_s` 期间位置命令平滑进入参考轨迹。
