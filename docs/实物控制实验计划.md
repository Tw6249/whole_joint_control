# 输入域 EID 与 Preview-MPC 的第一轮实物控制实验计划

本文档用于第一轮硬件实验。目标不是复刻完整仿真矩阵，而是在低风险、可复现、可回退的条件下，判断当前输入域 EID 和 Preview-MPC 是否值得进入更大幅值、更复杂工况。

当前代码状态需要先明确：

1. 参考域 EID 已从控制代码中删除。
2. 实物实验不再安排参考域 EID 组。
3. 第一轮只比较：
   - PD 基线；
   - 输入域 EID；
   - 零速五次样条与 2 点 Preview-MPC 的参考生成差异。
4. 当前没有拉力计、弹簧秤、绑带或外部力测量装置，因此第一轮不把“未知人工外力”作为主要定量扰动。
5. 第一轮 P2/P4 的主扰动采用**软件力矩偏置**，即在命令侧人为叠加已知、可记录、可重复的力矩扰动。

重要说明：

软件力矩偏置更接近仿真中的等效输入扰动，例如：

```text
tau_sent = tau_controller + tau_disturbance
```

它可以用于验证输入域 EID 对“等效输入扰动”的抑制能力，但不能单独支撑“真实外部物理推拉抗扰能力”的结论。若实验中出现人工触碰、线缆牵拉或机械碰撞，只作为异常事件或定性观察，不纳入 P2/P4 的通过判据。

---

## 1. 第一轮只回答四个问题

第一轮实物实验只回答以下问题：

1. 输入域 EID 在无外扰、低幅膝髋运动中是否不会带来明显副作用。
2. 输入域 EID 在单关节软件力矩扰动下是否能改善受扰关节误差，并且是否减少扰动向另一关节的传递。
3. Preview-MPC 是否能降低参考加速度、参考 jerk 或力矩变化量，同时不破坏基本跟踪。
4. EID 观测器增益和输入补偿强度如何影响扰动抑制能力、力矩代价和膝髋联动中的耦合响应。

这四个问题对应：

| 编号 | 目的 |
|---|---|
| P1 | 无扰动门槛验证 |
| P2 | 单关节软件力矩扰动与耦合响应验证 |
| P3 | Preview-MPC 参考生成验证 |
| P4 | $K_o$ 与 $K_u$ 补偿强度扫描 |

推荐执行顺序：

```text
P0 前置检查
    ↓
P1 无扰动门槛验证
    ↓
P2 单关节软件力矩扰动验证
    ↓
P4 K_o / K_u 参数扫描
    ↓
P3 Preview-MPC 参考生成验证
```

若台架时间有限，优先完成：

```text
P0 → P1 → P2
```

若 P2 已经显示输入域 EID 有收益但力矩代价偏大，应紧接着做 P4。
P3 只有在参考轨迹尖峰、速度激励或力矩变化量已经成为主要问题时才提前。

## 2. 第一轮安全边界

第一轮只允许在悬挂或可靠机械保护条件下进行。

第一轮不做：

1. 自由站立扰动实验。
2. 高幅度扰动实验。
3. 高功率髋膝联合扰动。
4. 参考域 EID。
5. 输入域 EID 与 Preview-MPC 的完整因子组合。
6. 未记录完整数据的实验。
7. 只展示单次曲线、不做重复和统计的实验。

第一轮默认原则：

```text
先单关节
再髋膝双关节

先 PD
再输入域 EID

先无扰动
再软件力矩扰动

先低幅值
再逐步增加

先固定参数
再参数扫描
```

## 4. 通用硬停止条件

以下任一条件触发，立即停止当前 trial，并暂停进入下一组参数。

| 编号 | 停止条件 | 处理 |
|---|---|---|
| S1 | 急停、安全线程退出、通信异常或 lowstate_age 超阈值 | 停止实验，检查通信与安全状态 |
| S2 | 髋/膝位置误差超过安全阈值并持续超过 N 个控制周期 | 停止当前 trial |
| S3 | 髋/膝速度超过安全阈值 | 停止当前 trial |
| S4 | 命令力矩达到限幅并持续超过 N 个控制周期 | 停止当前参数组 |
| S5 | `eta_u` 或 `tau_rate` 出现明显尖峰，超过 P1 PD 基线均值 + 3σ | 停止当前参数组 |
| S6 | 控制周期 `loop_dt` 连续超时 | 停止实验，检查实时性 |
| S7 | 出现机械干涉、线缆拉扯、结构振动或异常声音 | 停止实验 |
| S8 | 输入域 EID 出现持续振荡或明显偏置 | 回退 EID 参数 |

第一版建议先设置保守阈值：

```text
位置误差安全阈值：待根据关节幅值设定
速度安全阈值：待根据硬件安全范围设定
连续限幅周期数 N：建议从 5 ~ 10 个控制周期起步
loop_dt 超时阈值：根据 500 Hz 控制周期设定
```

## 5. 软件力矩扰动设计

由于没有外部力测量装置，P2/P4 的主要扰动采用软件力矩偏置。

### 5.1 扰动注入位置

推荐扰动注入方式：

```text
tau_controller = controller_output

tau_before_limit = tau_controller + tau_disturbance

tau_sent = clip(tau_before_limit, -tau_limit, tau_limit)
```

其中：

| 变量 | 含义 |
|---|---|
| `tau_controller` | PD 或输入域 EID 控制器输出 |
| `tau_disturbance` | 软件注入的等效输入扰动力矩 |
| `tau_before_limit` | 限幅前的合成力矩 |
| `tau_sent` | 实际发送到电机的限幅后力矩 |

必须记录：

```text
tau_controller
tau_disturbance
tau_before_limit
tau_sent
tau_limit
saturation_flag
```

这样可以区分：

1. 控制器自己输出变大；
2. 软件扰动叠加导致力矩变大；
3. 力矩限幅造成实际输入被削顶。

### 5.2 扰动波形

不建议第一版使用阶跃扰动，因为阶跃会引入很强高频成分。

推荐使用半余弦平滑矩形扰动：

```text
tau_disturbance(t) = A · smooth_window(t)
```

其中 `smooth_window(t)` 包含：

```text
ramp up
hold
ramp down
```

建议初值：

| 参数 | 建议 |
|---|---|
| 扰动开始时间 | 运动稳定后，例如 t = 2.0 s |
| 扰动持续时间 | 0.3 ~ 0.5 s |
| 上升/下降时间 | 0.05 ~ 0.1 s |
| 扰动幅值 | 不超过当前 `tau_limit` 的 10% ~ 20% |
| 扰动方向 | 第一版先固定一个方向；稳定后可测正负两个方向 |

示例：

```text
trial duration = 8.0 s
disturbance start = 2.5 s
disturbance end = 3.0 s
ramp time = 0.1 s
A = 0.1 * tau_limit
```

### 5.3 扰动窗口

每次扰动实验至少定义三个窗口：

```text
pre-window:
    扰动开始前 0.5 s

during-window:
    扰动开始到扰动结束

post-window:
    扰动结束后 1.0 s
```

记为：

```text
W_pre    = [t_start - 0.5, t_start)
W_during = [t_start, t_end]
W_post   = (t_end, t_end + 1.0]
```

P2/P4 的核心指标主要在 `W_during` 和 `W_post` 内计算。

## 6. 推荐实验清单

| 编号 | 实验 | 对比对象 | 工况 | 重复次数 | 主要判断 |
|---|---|---|---|---:|---|
| P1 | 无扰动门槛验证 | PD vs 输入域 EID | 低幅同相膝髋运动，无扰动 | 各 10 次 | 输入域 EID 是否引入额外误差、振荡、力矩压力或安全退出 |
| P2 | 单关节软件力矩扰动与耦合响应验证 | PD vs 输入域 EID | 低幅反相膝髋运动，分别对髋和膝注入软件力矩偏置 | 每个扰动子工况各 3 次 | 输入域 EID 是否改善受扰关节误差，并是否抑制扰动传到另一关节 |
| P4 | $K_o$ 与 $K_u$ 扫描 | 多组输入域 EID 参数 | 采用 P2 中最稳定、最可重复的一个扰动子工况 | 每组至少 3 次 | 观测器增益和输入补偿强度对误差、力矩和耦合响应的影响 |
| P3 | Preview-MPC 参考生成验证 | 零速五次样条 vs 2 点 Preview-MPC | 低幅膝髋运动，无扰动；优先在 PD 下测试 | 各 3 次 | Preview-MPC 是否降低参考激励和力矩变化量，且不恶化跟踪 |

正式执行顺序：

```text
P1 → P2 → P4 → P3
```

若 P1 不通过，不进入 P2。
若 P2 中误差改善依赖明显更大的力矩 RMS 或更高力矩变化量，应先回到 EID 参数、滤波或速率限制。
若 P4 中 $K_o$ 增大只带来力矩粗糙而没有误差下降，应降低 $K_o$ 或增强滤波。
若 P3 在 PD 下已经破坏跟踪，不进入 EID + Preview-MPC 组合验证。

## 7. P1：无扰动门槛验证

### 7.1 目的

确认输入域 EID 在没有扰动时不会比 PD 明显更差。

### 7.2 工况

```text
轨迹：低幅同相髋膝轨迹
扰动：无
控制方案：PD，输入域 EID
重复次数：各 10 次
```

第一轮建议先做 smoke test：

```text
PD 1 次
输入域 EID 1 次
```

若 smoke test 无异常，再做正式重复实验。

### 7.3 执行方式

建议正式统计时采用交错顺序，减少温度、通信状态和机械状态变化带来的偏差：

```text
PD → EID → EID → PD
```

重复若干组，直到每种方案达到 10 次。

### 7.4 通过条件

输入域 EID 相比 PD 应满足：

| 指标 | 第一版建议门槛 |
|---|---|
| 髋 RMSE | 不超过 PD 均值的 1.2 ~ 1.3 倍 |
| 膝 RMSE | 不超过 PD 均值的 1.2 ~ 1.3 倍 |
| 协调误差 RMSE | 不超过 PD 均值的 1.3 倍 |
| 力矩 RMS | 不超过 PD 均值的 1.3 ~ 1.5 倍 |
| 力矩变化量 RMS | 不超过 PD 均值的 1.5 倍 |
| 限幅次数 | 理想为 0；不得出现连续限幅 |
| 急停次数 | 必须为 0 |
| 状态时序 | 不得出现持续振荡、明显偏置或速度尖峰 |

若 P1 不通过，不进入 P2/P4。

## 8. P2：单关节软件力矩扰动与耦合响应验证

### 8.1 目的

验证输入域 EID 在可重复的软件等效输入扰动下是否保留抗扰收益，并判断一个关节被扰动时，另一关节是否通过膝髋联动出现可观测误差传递。

### 8.2 扰动性质说明

P2 的主扰动是软件力矩偏置：

```text
tau_sent = clip(tau_controller + tau_disturbance, tau_limit)
```

该实验结论应表述为：

```text
输入域 EID 对等效输入扰动的抑制能力
```

不应表述为：

```text
输入域 EID 对真实外部物理推拉的抗扰能力
```

### 8.3 子工况

P2 至少包含两个子工况：

| 子工况 | 扰动对象 | 主要观察量 | 目的 |
|---|---|---|---|
| P2-H | 髋关节软件力矩扰动 | 髋误差、膝误差、协调误差、髋/膝力矩响应 | 判断髋扰动是否传递到膝关节，并比较 PD 与输入域 EID 的协调保持能力 |
| P2-K | 膝关节软件力矩扰动 | 膝误差、髋误差、协调误差、髋/膝力矩响应 | 判断膝扰动是否反向影响髋关节，并检查输入域 EID 是否只改善局部误差而牺牲联动 |

P2-HK，即同时对髋膝注入小幅扰动，不作为第一轮通过条件。只有 P2-H 和 P2-K 均稳定后，后续扩展才考虑 P2-HK。

### 8.4 工况设置

```text
轨迹：低幅反相膝髋运动
控制方案：PD，输入域 EID
扰动方式：软件力矩偏置
扰动波形：半余弦平滑矩形扰动
扰动窗口：固定时间窗口
重复次数：每个子工况下，PD 与 EID 各至少 3 次
```

建议正式顺序：

```text
P2-H:
    PD-H → EID-H → EID-H → PD-H

P2-K:
    PD-K → EID-K → EID-K → PD-K
```

### 8.5 误差定义

设髋、膝位置跟踪误差为：

$$
e_h(t)=q_{h,\mathrm{ref}}(t)-q_h(t)
$$

$$
e_k(t)=q_{k,\mathrm{ref}}(t)-q_k(t)
$$

膝髋协调误差定义为：

$$
e_{\mathrm{coord}}(t)=e_h(t)-e_k(t)
$$

等价地：

$$
e_{\mathrm{coord}}(t)
=
\left(q_{h,\mathrm{ref}}(t)-q_{k,\mathrm{ref}}(t)\right)
-
\left(q_h(t)-q_k(t)\right)
$$

### 8.6 扰动窗口指标

在扰动窗口 $W_d$ 内计算：

$$
\mathrm{RMSE}_h^d=\mathrm{rms}(e_h)
$$

$$
\mathrm{RMSE}_k^d=\mathrm{rms}(e_k)
$$

$$
\mathrm{RMSE}_{\mathrm{coord}}^d=\mathrm{rms}(e_{\mathrm{coord}})
$$

以及：

$$
E_{\mathrm{coord,peak}}^d=\max_t |e_{\mathrm{coord}}(t)|
$$

### 8.7 扰动增量指标

为了避免把本来存在的跟踪误差误判为扰动响应，需要计算扰动前后的增量指标。

例如：

$$
\Delta \mathrm{RMSE}_h^d
=
\mathrm{RMSE}_{h,\mathrm{during}}
-
\mathrm{RMSE}_{h,\mathrm{pre}}
$$

$$
\Delta \mathrm{RMSE}_k^d
=
\mathrm{RMSE}_{k,\mathrm{during}}
-
\mathrm{RMSE}_{k,\mathrm{pre}}
$$

$$
\Delta \mathrm{RMSE}_{\mathrm{coord}}^d
=
\mathrm{RMSE}_{\mathrm{coord,during}}
-
\mathrm{RMSE}_{\mathrm{coord,pre}}
$$

P2/P4 应同时报告：

```text
窗口 RMSE
增量 RMSE
峰值误差
恢复时间
```

### 8.8 交叉传递比例

对于 P2-H，即髋扰动，受扰关节为髋，非受扰关节为膝。

定义髋到膝的交叉传递比例：

$$
\rho_{h\rightarrow k}
=
\frac{\mathrm{RMSE}_k^d}{\max(\mathrm{RMSE}_h^d,\epsilon)}
$$

对于 P2-K，即膝扰动，受扰关节为膝，非受扰关节为髋。

定义膝到髋的交叉传递比例：

$$
\rho_{k\rightarrow h}
=
\frac{\mathrm{RMSE}_h^d}{\max(\mathrm{RMSE}_k^d,\epsilon)}
$$

其中 $\epsilon$ 用于避免分母过小导致比例不稳定。

第一版可取：

```text
epsilon = 2 ~ 3 倍 P1 无扰动对应关节 RMSE 均值
```

交叉传递比例越大，说明扰动越容易通过膝髋联动传到另一关节。
交叉传递比例越小，说明非受扰关节在扰动窗口内越稳定。

### 8.9 抑制比例

输入域 EID 相对 PD 的协调抑制比例：

$$
S_{\mathrm{coord}}
=
\frac{\mathrm{RMSE}_{\mathrm{coord,EID}}^d}
{\mathrm{RMSE}_{\mathrm{coord,PD}}^d}
$$

输入域 EID 相对 PD 的交叉传递抑制比例：

$$
S_{\mathrm{cross}}
=
\frac{\rho_{\mathrm{EID}}}{\rho_{\mathrm{PD}}}
$$

若：

```text
S_coord < 1
```

说明输入域 EID 降低了扰动窗口内的协调误差。

若：

```text
S_cross < 1
```

说明输入域 EID 降低了扰动向另一关节传播的比例。

### 8.10 最小通过条件

P2-H 髋扰动可称为“抑制扰动传播”的最低条件：

```text
RMSE_k,EID^d < RMSE_k,PD^d

RMSE_coord,EID^d < RMSE_coord,PD^d

rho_h→k,EID < rho_h→k,PD
```

P2-K 膝扰动可称为“抑制扰动传播”的最低条件：

```text
RMSE_h,EID^d < RMSE_h,PD^d

RMSE_coord,EID^d < RMSE_coord,PD^d

rho_k→h,EID < rho_k→h,PD
```

整体 P2 通过条件：

| 项目 | 要求 |
|---|---|
| 受扰关节窗口 RMSE | EID 相比 PD 下降，或与 PD 接近但协调误差明显下降 |
| 非受扰关节窗口 RMSE | 不超过 PD 的 1.2 ~ 1.3 倍 |
| 协调误差 RMSE | EID 相比 PD 下降，或不恶化 |
| 交叉传递比例 | EID 相比 PD 下降更好 |
| 峰值协调误差 | 不明显增大 |
| 恢复时间 | 不明显变长 |
| 力矩 RMS | 不出现不可接受上升 |
| 力矩变化量 RMS | 不出现不可接受上升 |
| 限幅次数 | 不出现连续限幅 |
| 急停次数 | 必须为 0 |

若只满足受扰关节误差下降，但非受扰关节误差、协调误差或交叉传递比例上升，说明当前逐关节输入域 EID 可能改善了局部扰动跟踪，但没有抑制膝髋耦合传播。

## 9. P4：$K_o$ 与 $K_u$ 补偿强度扫描

### 9.1 目的

系统评估 EID 观测器增益和输入补偿强度对扰动抑制能力的影响。

重点关注：

1. 增大 $K_o$ 是否降低扰动窗口误差。
2. 增大 $K_o$ 是否主要增加力矩活动。
3. 增大 $K_o$ 是否放大非受扰关节误差。
4. 是否存在“误差继续下降但力矩代价快速上升”的拐点。
5. 当前逐关节输入域 EID 是否会通过机器人真实动力学耦合间接影响另一关节。

### 9.2 当前代码含义

代码中的 $K_o$ 对应每个关节的：

```text
observer_gain_q
observer_gain_dq
```

当前实现是逐关节对角形式，不是完整的非对角多关节观测器矩阵。

代码中的 $K_u$ 对应：

```text
ku_q
ku_dq
```

其作用是把 EID 状态估计量映射成输入端补偿力矩。

因此，第一轮 $K_o$ 扫描观察的是：

```text
逐关节观测器增益变化通过真实机器人动力学耦合产生的间接影响
```

不是：

```text
显式非对角耦合补偿
```

若要验证显式髋膝交叉补偿，需要后续实现：

$$
K_u \in \mathbb{R}^{2 \times 4}
$$

或多关节观测器。

### 9.3 P4 范围控制

P4 不在第一轮全面扫所有扰动方向。

推荐做法：

```text
从 P2-H 和 P2-K 中选择一个最稳定、最可重复、PD 与 EID 差异最清楚的子工况进入 P4。
```

如果 P2-H 更稳定，则 P4 采用 P2-H。
如果 P2-K 更稳定，则 P4 采用 P2-K。

第一轮 P4 只用于确认安全可用区间，不追求最优参数。

### 9.4 扫描原则

1. 固定 `kp/kd`。
2. 固定参考轨迹。
3. 固定力矩限幅。
4. 固定扰动窗口。
5. 固定扰动波形。
6. 固定扰动幅值。
7. 固定 `filter_alpha`。
8. 先扫 $K_o$。
9. 只有在 $K_o$ 找到稳定区间后，才可选扫 $K_u$。
10. 不同时改变 $K_o$ 和 $K_u$。

### 9.5 $K_o$ 扫描

建议第一轮使用相对缩放，而不是直接指定绝对值。

| 组别 | `observer_gain_q` / `observer_gain_dq` | `ku_q` / `ku_dq` | 目的 |
|---|---|---|---|
| O0 | 0，且 EID 状态 reset 并保持 `eta_u = 0` | 可保持配置但不生效 | 干净的 EID 估计通道关闭对照 |
| O1 | 0.25 倍基准值 | 保持基准值 | 很弱观测器，检查是否已有轻微抑制收益 |
| O2 | 0.50 倍基准值 | 保持基准值 | 中低观测器增益 |
| O3 | 0.75 倍基准值 | 保持基准值 | 接近基准但仍保守 |
| O4 | 1.00 倍基准值 | 保持基准值 | 当前候选参数 |
| O5 | 1.25 倍基准值 | 保持基准值 | 仅在 O4 稳定且力矩不粗糙时测试 |

O0 必须满足：

```text
observer_gain_q = 0
observer_gain_dq = 0
eta_q reset to zero
eta_dq reset to zero
eta_u reset to zero
eta_u remains zero during trial
```

否则 O0 不能作为干净对照。

### 9.6 $K_u$ 扫描

只有当 O1 ~ O4 稳定，但扰动抑制不足时，才进行 $K_u$ 扫描。

| 组别 | $K_o$ | `ku_q` / `ku_dq` | 目的 |
|---|---|---|---|
| U1 | 选定稳定 $K_o$ | 0.50 倍基准值 | 弱输入补偿 |
| U2 | 选定稳定 $K_o$ | 0.75 倍基准值 | 中等输入补偿 |
| U3 | 选定稳定 $K_o$ | 1.00 倍基准值 | 当前候选补偿 |
| U4 | 选定稳定 $K_o$ | 1.25 倍基准值 | 仅在 U3 稳定且力矩代价可接受时测试 |

若 U3 已经显示明显噪声放大、力矩变化量增加或非受扰关节误差变大，则不测试 U4。

### 9.7 P4 停止条件

以下任一情况出现，停止继续增大 $K_o$ 或 $K_u$：

1. 急停。
2. 持续振荡。
3. 力矩接近限幅。
4. 连续限幅。
5. 力矩变化量 RMS 明显上升。
6. `eta_u` 出现高频抖动。
7. 非受扰关节窗口 RMSE 明显变大。
8. 协调误差 RMSE 明显变大。
9. 误差下降已经很小，但力矩代价继续快速上升。

### 9.8 P4 必须交付结果

P4 必须交付两类结果。

第一类：补偿强度扫描表。

每行对应一个参数组，至少包含：

```text

K_u 缩放

tau_limit

非受扰关节窗口 RMSE

交叉传递比例

S_cross
恢复时间

力矩变化量 RMS

eta_u rate RMS

```

第二类：RMSE 与力矩指标对比图。

横轴为：

```text

```

或：

```text

```

纵轴至少包含：


P4 的结论不能只写“某个增益最好”。必须说明：

1. 增大 $K_o$ 是降低了扰动窗口误差，还是主要增加了力矩活动。
2. 增大 $K_o$ 对非受扰关节是否有副作用。
3. 增大 $K_u$ 是否造成过补偿、换向冲击或高频力矩。
4. 是否存在误差下降与力矩代价之间的折中区间。

### 10.1 目的

```text
Preview-MPC solve time
q_ref

QP failure flag
```

```text
轨迹：低幅膝髋运动
```

```text
输入域 EID + Preview-MPC
```

## 14. 高频扰动源分析

高频扰动不应预设为主要问题。第一轮只把它作为 P2/P4 的诊断项。

如果频谱中没有稳定的高频峰，或高频能量相对低频运动和扰动瞬态很小，就不应把性能问题归因于高频扰动。

可能的高频来源包括：

| 来源 | 可能表现 | 验证方式 |
|---|---|---|
| 速度测量噪声或差分噪声 | `dq_actual`、`eta_dq`、`eta_u` 抖动，力矩变化量升高 | 比较 PD 与 EID；检查 `eta_dq` 和 `eta_u` 频谱 |
| $K_o$ 过大或 `filter_alpha` 过大 | EID 估计量快速跟随噪声，补偿力矩变粗糙 | P4 中随 $K_o$ 增大观察 `eta_u` RMS 和力矩变化量 |
| 参考生成边界 | policy 周期附近出现速度或力矩尖峰 | 对齐策略周期，检查参考速度、参考加速度、力矩尖峰是否同步 |
| 控制周期抖动或通信延迟 | 状态更新时间不均匀，力矩出现非周期性跳变 | 记录 `loop_dt`、`lowstate_age`、安全状态 |
| 力矩限幅或饱和后的切换 | 力矩波形削顶，恢复后跳变 | 统计限幅次数，叠加力矩时序和限幅标志 |
| 机械结构或台架微振 | 某些频率固定出现，与控制方案关系不强 | 空载/低幅 PD 对照，检查相同频率是否存在 |

建议使用三层判断：

```text
1. 时域判断：
   观察力矩、力矩变化量、eta_u、速度误差是否存在持续快速振荡。

2. 频域判断：
   对上述信号计算频谱或功率谱，比较 PD、输入域 EID 和不同 K_o 组。

3. 归因判断：
   如果高频能量只随 K_o 增大而上升，优先怀疑观测器增益或滤波。
   如果 PD 中也存在同频峰，优先检查测量、通信或机械台架。
```

第一版高频定义采用相对判断：

```text
显著高于参考运动频率和扰动窗口瞬态主频的成分，才作为高频候选。
```

若日志采样率只有 50 Hz，则不能可靠诊断高频问题。
P2/P4 建议保存 500 Hz 控制环日志。

## 15. 不建议在第一轮做的实验

第一轮不建议做以下实验：

1. 参考域 EID。
2. EID 与 Preview-MPC 的完整因子组合。
3. 自由站立或高功率条件下的扰动实验。
4. 未知人工外力作为定量扰动实验。

6. P2-HK 髋膝联合扰动。
7. 在 P1 不通过时做 P2/P4。
8. 在 Preview-MPC 尚未确认上机入口和回退机制时直接闭环。
9. 只看单次曲线、不做重复实验和指标表的实验。

## 16. 第一轮结束后的决策

第一轮结束后，应给出四个明确结论：

1. 输入域 EID 是否可以进入下一轮硬件扰动实验。
2. 输入域 EID 的主要收益来自受扰关节误差改善、协调误差改善，还是扰动恢复改善。
3. Preview-MPC 是否可以作为后续硬件实验的默认参考生成候选。
4. $K_o$ 和 $K_u$ 是否存在可用调节区间，以及是否观察到明显的膝髋耦合副作用。

### 16.1 若 P1 不通过

优先回到：

```text
EID 观测器增益
输入补偿增益
filter_alpha
力矩限幅
力矩速率限制
x_bar / eta 初值复位
速度估计噪声
```

不要进入 P2/P4。

### 16.2 若 P2 不通过

不要直接增加扰动强度。

优先检查：

```text
软件扰动注入位置是否正确

eta_u 是否过度抖动
力矩限幅是否削顶
非受扰关节误差是否被放大
控制周期是否稳定
```

### 16.3 若 P4 显示增大 $K_o$ 只带来力矩粗糙

```text
降低 K_o
降低 filter_alpha
降低速度通道 observer_gain_dq
降低 ku_dq
加入 eta_u 速率限制
检查速度估计噪声
```

不要继续增大补偿。


不要直接接入：


## 18. 本轮结论的表述边界

由于第一轮没有外部力测量装置，结论表述必须保守。

可以表述为：

```text
输入域 EID 在软件等效输入扰动下表现出扰动窗口误差下降。
```

可以表述为：

```text
输入域 EID 在当前硬件、当前轨迹和当前力矩限幅下，没有在无扰动低幅运动中引入明显副作用。
```

可以表述为：

```text
输入域 EID 降低了软件扰动从受扰关节向非受扰关节传播的比例。
```

不应表述为：

```text
输入域 EID 已经验证真实外部物理推拉抗扰能力。
```

不应表述为：

```text
输入域 EID 已经全面优于 PD。
```

不应表述为：

```text
Preview-MPC 已经证明硬件安全性。
```

第一轮的核心结论应限制在：

```text
低幅、受保护、软件等效输入扰动、当前控制参数、当前硬件日志可观测范围内。
```
