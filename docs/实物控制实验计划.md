# 输入域 EID 与 Preview-MPC 的第一轮实物控制实验计划

本文档根据《输入域与参考域 EID 以及 MPC 插值研究报告》的“下一步计划：实物实验验证”整理第一轮硬件实验。目标不是复刻全部仿真矩阵，而是用低风险、可复现的实验判断当前输入域 EID 和 Preview-MPC 是否值得继续进入更大幅值、更复杂工况。

当前代码状态需要先明确：参考域 EID 已从控制代码中删除，硬件实验只比较 PD、输入域 EID，以及参考生成方式的差异。后续实物实验不再安排参考域 EID 组。

## 1. 第一轮只回答四个问题

第一轮实物实验建议只回答以下问题：

1. 输入域 EID 在无外扰、低幅膝髋运动中是否不会带来明显副作用。
2. 输入域 EID 在单关节轻扰动下是否仍能改善受扰关节误差，并确认解耦假设下另一关节没有不可接受的副作用。
3. Preview-MPC 是否能降低参考加速度、参考 jerk 或力矩变化量，同时不破坏基本跟踪。
4. EID 观测器增益和补偿强度如何影响单关节扰动抑制能力、力矩代价和解耦通道的稳定性。

这四个问题对应 P1、P2、P3、P4。若台架时间有限，优先做 P1 和 P2；P4 应紧跟 P2，因为它直接回答补偿强度和 $K_o$ 调节对抑制能力的影响。P3 只有在参考轨迹尖峰、力矩变化量或速度激励已经成为主要问题时才提前。

## 2. 实验前置检查

在进入 P1 前，需要完成以下准备。

| 编号 | 项目 | 要求 | 不通过时的处理 |
|---|---|---|---|
| P0-1 | 机械保护 | 机器人悬挂或有可靠机械限位保护，急停可用，旁边有人看护 | 不上电闭环 |
| P0-2 | 只读状态检查 | 运行 `h1_knee_state`，确认 joint_id、关节正方向、零位、限位、lowstate_age 正常 | 修正配置或通信 |
| P0-3 | 单关节 PID bring-up | 先用 `h1_knee_pid` 做单关节小幅运动，确认力矩限幅和方向正确 | 不进入多关节 EID |
| P0-4 | 配置收敛 | 第一次只启用一个关节，随后再启用髋膝两个关节；`policy_amplitude`、`kp/kd`、`tau_limit` 从小值开始 | 回退到更小幅值 |
| P0-5 | 日志完整性 | 至少能记录参考、实际状态、命令力矩、安全标志、实验编号和重复编号 | 先修日志再做实验 |

推荐命令入口沿用 README 中的实机流程：

```bash
./build-h1/h1_knee_state config/h1_full_body_mujoco_fit.yaml

sudo ./build-h1/h1_knee_pid config/h1_full_body_mujoco_fit.yaml 0.55 8 --arm \
    --kp 30 --ki 1 --kd 3 --tau-limit 12 --speed 0.15

sudo ./build-h1/h1_direct config/h1_full_body_mujoco_fit.yaml
```

实物配置中的 `network_interface` 和 `domain_id` 必须与当前机器人通信环境一致。默认配置可作为起点，但硬件实验的幅值、增益和力矩限幅应保守回退后再逐步放大。

## 3. 推荐实验清单

| 编号 | 实验 | 对比对象 | 工况 | 重复次数 | 主要判断 |
|---|---|---|---|---:|---|
| P1 | 无扰动门槛验证 | PD vs 输入域 EID | 低幅同相膝髋运动，无外扰 | 各 10 次 | 输入域 EID 是否引入额外误差、振荡、力矩压力或安全退出 |
| P2 | 单关节轻扰动验证 | PD vs 输入域 EID | 低幅反相膝髋运动，分别施加髋扰动和膝扰动 | 每个扰动子工况各 3 次 | 输入域 EID 是否改善受扰关节误差，并检查另一关节是否出现不可接受的副作用 |
| P3 | Preview-MPC 参考生成验证 | 零速五次样条 vs 2 点 Preview-MPC | 低幅膝髋运动，无外扰；优先在 PD 下测试 | 各 3 次 | Preview-MPC 是否降低参考激励和力矩变化量，且不恶化跟踪 |
| P4 | $K_o$ 与补偿强度扫描 | 多组输入域 EID 参数 | 采用 P2 中最稳定的扰动方式，逐步提高 $K_o$，必要时再扫 $K_u$ | 每组至少 3 次 | 补偿强度对受扰关节误差、力矩 RMS、力矩变化量和解耦通道稳定性的影响 |

执行顺序建议为 P1 -> P2 -> P4 -> P3。P1 不通过时，不进入 P2；P2 中若误差改善依赖明显更大的力矩 RMS 或更高力矩变化量，应先回到输入域 EID 参数、滤波或速率限制调节。P4 不应在 P1 未通过时进行，因为参数扫描会扩大实验暴露面。

## 4. 各实验的具体设计

### P1：无扰动门槛验证

目的：确认输入域 EID 在没有外扰时不会比 PD 明显更差。

建议流程：

1. 机器人处于悬挂或可靠保护状态。
2. 使用低幅同相髋膝轨迹，先运行 PD，再运行输入域 EID。
3. 每种控制方案至少重复 10 次。
4. 若任一次出现急停、持续振荡、明显偏置或接近力矩边界，停止扩大幅值。

通过条件：

- 输入域 EID 相比 PD 不明显增大髋 RMSE、膝 RMSE、协调误差 RMSE。
- 输入域 EID 的力矩 RMS、力矩变化量 RMS 不出现不可接受上升。
- 10 次重复中无急停、无持续振荡、无明显通信或状态异常。

### P2：单关节轻扰动验证

目的：验证输入域 EID 在真实外扰或等效外扰下是否保留仿真中的抗扰收益。当前实验将髋、膝视作解耦控制通道，因此 P2 不验证髋膝交叉补偿，只检查单关节补偿是否会让另一关节出现不可接受的副作用。

必须先区分两类扰动：

- 物理外扰：由实验人员或外部装置对髋部/腿部施加可记录的轻扰动。这更接近“外界扰动”，但需要明确扰动时间、方向和幅值估计。
- 软件力矩偏置：在命令侧人为叠加力矩。这更接近仿真中的 `data.ctrl += tau_disturbance`，但它不是外界施加的物理扰动，不能单独支撑“外力抗扰”结论。

建议将 P2 的主实验定义为物理轻扰动；如果当前硬件条件无法稳定施加物理扰动，可以先做软件力矩偏置作为工程调试，但文档和结果中必须明确其性质。

[NEEDS AUTHOR INPUT: P2 采用哪种硬件扰动方式，例如人工短时推拉、弹簧/拉力计加载、绑带砝码加载，或软件力矩偏置。]

P2 不应只看髋关节扰动。至少应包含两个子工况：

| 子工况 | 扰动对象 | 主要观察量 | 目的 |
|---|---|---|---|
| P2-H | 髋关节轻扰动 | 髋误差、膝误差、协调误差、髋/膝力矩响应 | 判断髋通道 EID 是否改善髋关节局部抗扰，并检查膝关节副作用 |
| P2-K | 膝关节轻扰动 | 膝误差、髋误差、协调误差、髋/膝力矩响应 | 判断膝通道 EID 是否改善膝关节局部抗扰，并检查髋关节副作用 |

若 P2-H 和 P2-K 均稳定，再考虑 P2-HK，即小幅、短时、同方向或反方向的髋膝联合扰动。P2-HK 只用于后续扩展，不作为第一轮通过条件。

建议流程：

1. 使用低幅反相膝髋运动。
2. 先运行 PD，后运行输入域 EID。
3. 分别执行 P2-H 和 P2-K；每个子工况中 PD 和输入域 EID 各至少重复 3 次。
4. 每次实验记录扰动开始时间、结束时间、扰动方向和扰动幅值或估计外力。
5. 分别计算全时段指标、扰动窗口指标和非受扰关节副作用指标。

通过条件：

- 输入域 EID 相比 PD 至少降低受扰关节窗口 RMSE 或协调误差 RMSE 之一。
- 非受扰关节的 RMSE、峰值误差和力矩变化量不应明显恶化。
- 恢复时间或峰值协调误差不变差，或变差幅度可由力矩限制解释。
- 力矩 RMS、力矩变化量 RMS、限幅次数没有不可接受上升。

### P3：Preview-MPC 参考生成验证

目的：验证 Preview-MPC 是否能降低参考激励和力矩变化量。

建议先在 PD 下做 P3，而不是一开始就和输入域 EID 组合。理由是 P3 主要验证参考生成层，不是扰动补偿层；若 Preview-MPC 在 PD 下已经破坏跟踪，就不应继续接入 EID。

建议流程：

1. 使用低幅膝髋运动，无外扰。
2. 比较零速五次样条和 2 点 Preview-MPC。
3. 优先在 PD 控制下测试；若通过，再考虑输入域 EID + Preview-MPC。
4. 记录参考速度、参考加速度、参考 jerk、实际状态和力矩。

通过条件：

- 2 点 Preview-MPC 降低参考加速度 RMS、参考 jerk RMS 或力矩变化量 RMS 中至少一项。
- 髋/膝 RMSE 和协调误差 RMSE 不明显恶化。
- 不出现策略点附近的速度尖峰、跟踪跳变或异常力矩尖峰。

[VERIFY RESULT: 当前硬件控制入口是否已经接入 2 点 Preview-MPC 参考生成。若尚未接入，P3 应先作为离线/半实物参考生成测试，不直接进入上机闭环。]

### P4：$K_o$ 与补偿强度扫描

目的：系统评估 EID 观测器增益和输入补偿强度对单关节扰动抑制能力的影响，并检查增益提高是否带来力矩粗糙、噪声放大或非受扰关节副作用。

需要先说明当前代码含义。代码中的 $K_o$ 对应每个关节的 `observer_gain_q` 和 `observer_gain_dq`，目前按逐关节解耦通道使用。`ku_q` 和 `ku_dq` 则把该关节的 EID 状态估计量映射成该关节的输入端补偿力矩。因此，第一轮 $K_o$ 扫描只评价逐关节观测器和逐关节输入补偿的有效性与代价，不讨论髋膝交叉补偿。

推荐扫描方式：

1. 固定 `kp/kd`、参考轨迹、力矩限幅、扰动方式和 `filter_alpha`。
2. 从较小 $K_o$ 开始，逐步提高，不跳到大增益。
3. 每组参数至少重复 3 次；若某组出现急停、持续振荡、力矩接近限幅或明显高频力矩抖动，停止继续增大。
4. 先扫 $K_o$，再决定是否扫 $K_u$。不要同时改变 $K_o$ 和 $K_u$，否则无法判断收益来自估计增强还是补偿增强。

建议第一轮使用相对缩放，而不是直接指定绝对值：

| 组别 | `observer_gain_q` / `observer_gain_dq` | `ku_q` / `ku_dq` | 目的 |
|---|---|---|---|
| O0 | 0 | 保持基准值 | 近似关闭 EID 估计更新，作为 EID 估计通道对照 |
| O1 | 0.25 倍基准值 | 保持基准值 | 很弱观测器，检查是否已经有轻微抑制收益 |
| O2 | 0.50 倍基准值 | 保持基准值 | 中低观测器增益 |
| O3 | 0.75 倍基准值 | 保持基准值 | 接近基准但仍保守 |
| O4 | 1.00 倍基准值 | 保持基准值 | 当前候选参数 |
| O5 | 1.25 倍基准值 | 保持基准值 | 仅在 O4 稳定且力矩不粗糙时测试 |

若 O4 或 O5 已经显示明显噪声放大、力矩变化量增加或非受扰关节误差变大，则不继续提高 $K_o$。若 O1--O4 均稳定但扰动抑制不足，再设计 $K_u$ 扫描：

| 组别 | $K_o$ | `ku_q` / `ku_dq` | 目的 |
|---|---|---|---|
| U1 | 选定稳定 $K_o$ | 0.50 倍基准值 | 弱输入补偿 |
| U2 | 选定稳定 $K_o$ | 0.75 倍基准值 | 中等输入补偿 |
| U3 | 选定稳定 $K_o$ | 1.00 倍基准值 | 当前候选补偿 |
| U4 | 选定稳定 $K_o$ | 1.25 倍基准值 | 仅在 U3 稳定且力矩代价可接受时测试 |

P4 必须交付两类结果：

1. 补偿强度扫描表。每行对应一个参数组，列出髋/膝 $K_o$ 缩放、$K_u$ 缩放、扰动类型、受扰关节 RMSE、非受扰关节 RMSE、协调误差 RMSE、恢复时间、力矩 RMS、力矩变化量 RMS、限幅次数和单组结论。
2. RMSE 与力矩指标对比图。横轴为 $K_o$ 或 $K_u$ 缩放系数，纵轴至少包含受扰关节窗口 RMSE、协调误差 RMSE、力矩 RMS 和力矩变化量 RMS。建议同一张图中同时画出受扰关节和非受扰关节，以判断局部补偿收益和非受扰关节副作用。

P4 的结论不应只写“某个增益最好”。需要明确指出：增大 $K_o$ 是降低了扰动窗口误差，还是主要增加了力矩活动；它对非受扰关节的误差和力矩是否有副作用；是否存在一个“误差继续下降但力矩代价快速上升”的拐点。

每次实验都必须保存同一组基础信号，避免后续只能凭曲线主观判断。

| 类别 | 必须记录的量 | 用途 |
|---|---|---|
| 参考状态 | 髋/膝参考位置、参考速度；P3 另记录参考加速度和 jerk | 判断参考是否平滑、是否符合目标运动 |

| 实验信息 | 日期、实验编号、重复编号、控制方案、参考生成方案、配置文件快照 | 保证可追溯 |

每次实验结束后至少生成一张逐次实验指标表。建议列包括：

| 指标 | 适用实验 | 含义 |
|---|---|---|
| 髋 RMSE、膝 RMSE | P1/P2/P3/P4 | 基本跟踪精度 |

| 限幅次数、急停次数 | P1/P2/P3/P4 | 是否满足继续实验的安全条件 |

## 8. 高频扰动源分析

高频扰动不应预设为主要问题。当前更稳妥的做法是把“是否存在明显高频扰动”作为 P2 和 P4 的诊断项。如果频谱中没有稳定的高频峰，或高频能量相对低频运动和扰动瞬态很小，就不应把性能问题归因于高频扰动。

可能的高频来源包括：

| 来源 | 可能表现 | 验证方式 |
|---|---|---|
| 速度测量噪声或差分噪声 | `dq_actual`、`eta_dq`、`eta_u` 抖动，力矩变化量升高 | 比较 PD 与 EID；检查 `eta_dq` 和 `eta_u` 频谱 |
| $K_o$ 过大或 `filter_alpha` 过大 | EID 估计量快速跟随噪声，补偿力矩变粗糙 | P4 中随 $K_o$ 增大观察 `eta_u` RMS 和力矩变化量 |
| 参考生成边界 | 在 policy 周期附近出现速度或力矩尖峰 | 对齐策略周期，检查参考速度、参考加速度、力矩尖峰是否同步 |
| 控制周期抖动或通信延迟 | 状态更新时间不均匀，力矩出现非周期性跳变 | 记录控制周期、lowstate_age、安全状态 |
| 力矩限幅或饱和后的切换 | 力矩波形出现削顶、恢复后跳变 | 统计限幅次数，叠加力矩时序和限幅标志 |
| 机械结构、线缆或台架微振 | 某些频率固定出现，与控制方案关系不强 | 空载/低幅 PD 对照，检查相同频率是否存在 |

建议使用三层判断：

1. 时域判断：观察力矩、力矩变化量、`eta_u`、速度误差是否存在持续快速振荡。
2. 频域判断：对上述信号计算频谱或功率谱，比较 PD、输入域 EID 和不同 $K_o$ 组。
3. 归因判断：如果高频能量只随 $K_o$ 增大而上升，优先怀疑观测器增益或滤波；如果 PD 中也存在同频峰，优先检查测量、通信或机械台架。

[NEEDS AUTHOR INPUT: 根据实物控制频率、日志采样率和执行器带宽确定“高频”的具体频段阈值。第一版可先按相对判断处理：显著高于参考运动频率和扰动窗口瞬态主频的成分，才作为高频候选。]

## 9. 不建议在第一轮做的实验

第一轮不建议做以下实验：

1. 参考域 EID。该路径已从代码中删除，且仿真报告已将其判定为高风险方向。
2. EID 与 Preview-MPC 的完整因子组合。先分别验证底层补偿和参考生成。
3. 自由站立或高功率条件下的扰动实验。当前计划只适合悬挂或可靠机械保护条件。
4. 高幅度、多关节同时扰动。P2 先做髋单扰动和膝单扰动；联合扰动不作为第一轮解耦通道验证内容。
5. 只看单次曲线、不做重复实验和指标表的实验。

## 10. 第一轮结束后的决策

第一轮结束后，应给出三个明确结论：

1. 输入域 EID 是否可以进入下一轮硬件扰动实验。
2. 输入域 EID 的主要收益来自跟踪误差、协调误差，还是扰动恢复。
3. Preview-MPC 是否可以作为后续硬件实验的默认参考生成候选。
4. $K_o$ 和补偿强度是否存在可用调节区间，以及是否观察到明显的非受扰关节副作用。

若 P1 不通过，优先回到 EID 观测器增益、输入补偿增益、滤波、力矩限幅和速率限制调节。若 P2 不通过，不应直接增加扰动强度；应先检查 EID 估计量、力矩变化量和扰动施加方式。若 P4 显示 $K_o$ 增大只带来力矩粗糙而没有扰动窗口误差下降，应降低 $K_o$ 或加强滤波，而不是继续增大补偿。若 P3 不通过，应先约束 Preview-MPC 的速度、加速度、jerk 和策略点跳变，再考虑上机组合验证。
