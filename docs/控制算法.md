# 控制算法说明

本文只保留当前工程仍在使用的控制链路说明。参考生成层中的基础 MPC 为：

```yaml
policy_interpolation: preview_mpc
policy_reference_points: 3
```

另有一个不污染基础方法的速度参考变体：

```yaml
policy_interpolation: preview_mpc_velocity
policy_reference_points: 4
```

## 1. 参考生成

策略层以 `policy_dt` 给出低频关节位置点，控制层以 `control_dt` 执行。对普通插值，工程仍保留：

- `open_loop`：按策略点生成开环参考；
- `closed_loop`：每个策略段从当前实测状态接入目标点。

对 MPC 插值，`preview_mpc` 固定使用 3 参考点 soft-preview no-terminal 方法。设：

```math
N_p=\mathrm{round}(policy\_dt/control\_dt),\qquad N_h=3N_p
```

状态为：

```math
x_k=
\begin{bmatrix}
q_k & \dot q_k & \ddot q_k
\end{bmatrix}^T
```

决策变量为窗口内 jerk：

```math
J=
\begin{bmatrix}
j_0 & j_1 & \cdots & j_{N_h-1}
\end{bmatrix}^T
```

离散积分后得到线性预测：

```math
q=q_b+A_qJ,\qquad
\dot q=\dot q_b+A_vJ,\qquad
\ddot q=\ddot q_b+A_aJ
```

第一个策略点硬约束：

```math
q_{N_p}=q_0^{\ast}
```

第 2、3 个策略点作为软预览目标：

```math
q_{2N_p}\approx q_1^{\ast},\qquad q_{3N_p}\approx q_2^{\ast}
```

目标函数为：

```math
\min_J
\sum_{k=1}^{N_h}
\left(w_v\dot q_k^2+w_a\ddot q_k^2\right)
+w_j\sum_i j_i^2
+w_p\left[(q_{2N_p}-q_1^{\ast})^2+(q_{3N_p}-q_2^{\ast})^2\right]
+w_r\sum_i j_i^2
```

该目标不包含 terminal velocity/acceleration 惩罚项。完整推导见 [MPC方法梳理.md](MPC方法梳理.md)。

`preview_mpc_velocity` 保留上述三点方法的位置软预览、路径速度/加速度、jerk 和 ridge 项，同时要求策略输出 4 个位置点。第 4 个点只用于差分构造前三个策略点的速度目标：

```math
v_i^\ast=\frac{q_{i+1}^\ast-q_i^\ast}{policy\_dt},\qquad i=0,1,2
```

目标函数额外加入：

```math
w_{pv}\sum_{i=0}^{2}\left(\dot q_{(i+1)N_p}-v_i^\ast\right)^2,\qquad w_{pv}=1.0
```

该变体仍只执行第一个策略周期的参考序列，下一策略周期滚动重算。

## 2. Position PD

位置 PD 控制器直接下发电机位置模式命令：

```math
q_\mathrm{cmd}=q^{\ast},\qquad
\dot q_\mathrm{cmd}=\dot q^{\ast}
```

```math
K_p=kp,\qquad K_d=kd,\qquad \tau_\mathrm{ff}=0
```

启动阶段使用 `startup_blend_duration_s` 从实测初始位置平滑混入参考轨迹，避免第一帧命令跳变。

## 3. 输入域 EID

EID 控制器仍以参考状态为中心构造反馈和补偿。单关节状态：

```math
x_k=
\begin{bmatrix}
q_k & \dot q_k
\end{bmatrix}^T,\qquad
r_k=
\begin{bmatrix}
q_k^{\ast} & \dot q_k^{\ast}
\end{bmatrix}^T
```

名义 PD 误差：

```math
e_k=r_k-x_k
```

输入域补偿量经 `ku_q/ku_dq` 映射后叠加到控制输入。安全限幅、力矩斜率限制和 joint limit 检查仍在最终命令下发前执行。

## 4. 配置约束

- `preview_mpc` 必须使用 `policy_reference_points: 3`。
- `preview_mpc_velocity` 必须使用 `policy_reference_points: 4`。
- `policy_mpc_variant` 已删除，配置中出现该字段会报错。
- `open_loop` 和 `closed_loop` 不是 MPC 方法，作为基础参考插值能力保留。
