历史 P3 中的旧 MPC 对比内容已从当前项目入口文档中移除。当前工程只保留并继续使用一种 MPC 参考生成方法：

```yaml

```

该方法为 3 参考点 soft-preview MPC，且不包含 terminal velocity/acceleration 惩罚项。算法公式和工程接口见 [MPC方法梳理.md](MPC方法梳理.md)。

```text
config/h1_real_p3_selected_mpc_hip_knee_pd.yaml
```

后续新增结果总结应只围绕当前唯一 MPC 方法、PD/EID 控制器和实际实验数据展开，不再加入旧 MPC 变体或旧对比基线。
